# Phantomanta


[>> Downloads <<](https://modrinth.com/mod/phantomanta)

*Beware what lurks in the deep...*

**This mod is open source and under a permissive license.** As such, it can be included in any modpack on any platform without prior permission. We appreciate hearing about people using our mods, but you do not need to ask to use them. See the [LICENSE file](LICENSE) for more details.

Phantomanta transforms phantoms into manta rays that attack from the water at night. They can no longer fly through the air, but will still leap out to attack you if you get too close.

This mod is pretty simple, so I will do my best to port it to a few versions, but no promises!

This mod was made as a project for [Mogswamp](https://www.youtube.com/@Mogswamp)!
